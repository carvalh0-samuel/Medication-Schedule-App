# 💊 Saúde em Dia - Aplicativo de Gestão e Lembrete de Medicamentos
Aplicativo mobile desenvolvido em React Native e Expo com foco em saúde e bem-estar, projetado para auxiliar utilizadores no controle rigoroso de tratamentos médicos, horários de posologia e adesão a medicamentos.

# 🚀 Principais Funcionalidades
Cadastro Inteligente de Posologia: Registo de nomes, doses e horários iniciais com formatação automática de horas (HH:MM).

Cálculo Automático de Frequência: Suporte para intervalos médicos padrão (Dose única, 6 em 6h, 8 em 8h, 12 em 12h, etc.), gerando os horários do dia automaticamente.

Notificações Nativas: Integração com o sistema operativo para envio de lembretes e alarmes nos horários programados.

Controle de Progresso Diário: Dashboard dinâmico com barra de progresso em tempo real baseada nos medicamentos já tomados no dia.

Persistência Local de Dados: Armazenamento seguro e offline utilizando AsyncStorage, garantindo que os dados não se percam ao fechar a aplicação.

Interface Moderna & Responsiva: Design limpo inspirado em padrões de UI/UX modernos, com suporte a modais fluidos, feedback tátil e paleta de cores focada em saúde.

# 🛠️ Tecnologias Utilizadas
React Native / Expo (Framework principal)

JavaScript (ES6+)

React Hooks (useState, useEffect)

AsyncStorage (Persistência local)

Expo Notifications (Gestão de alarmes nativos)

Vector Icons (@expo/vector-icons)

EAS Build (Compilação e geração de APK para Android)
